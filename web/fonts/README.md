# Typography

Inter Variable is the reading and control typeface. It is served locally for
headings, messages, password inputs, navigation and actions. Fingerprints retain
their monospace font. Michroma is reserved for the ToneSeal wordmark. No runtime
request goes to a font provider. Font files are unmodified.
